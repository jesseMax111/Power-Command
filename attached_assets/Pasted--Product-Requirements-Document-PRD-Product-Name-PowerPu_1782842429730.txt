# Overview

PowerPulse is a community-driven mobile application that enables users to report and monitor electricity availability in real time. Instead of relying on utility companies for updates, users contribute live reports that help everyone know whether electricity is available, when outages started, when power was restored, and whether infrastructure such as transformers has failed.

The app should provide a live map of electricity status, crowd-verified reports, outage history, and notifications for saved locations.

---

# Problem

People living in areas with unreliable electricity constantly ask questions like:

* Is power out only in my house?
* Has anyone nearby gotten electricity?
* How long has the outage lasted?
* Did the transformer explode?
* Is there any official update?

Currently, these answers are scattered across WhatsApp groups, phone calls, Facebook posts, or word of mouth.

PowerPulse centralizes this information into one platform.

# Vibe Coding Prompt

> Build a modern cross-platform mobile app called **PowerPulse** using React Native (Expo), TypeScript, NativeWind, Supabase (Authentication, PostgreSQL, Realtime, Storage), and React Query. The app enables users to report electricity outages, power restorations, and transformer faults. It should include secure authentication, GPS-based reporting, an interactive map with color-coded status markers, real-time updates using Supabase Realtime, community verification (confirm/dispute reports), saved locations with push notifications, outage history, neighborhood reliability statistics, and a clean, minimalist UI inspired by Google Maps and Notion. Structure the project with scalable feature-based folders, reusable components, offline support for queued reports, and production-ready architecture suitable for future AI prediction and utility company integrations.
